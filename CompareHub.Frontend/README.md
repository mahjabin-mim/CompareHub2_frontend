# CompareHub Frontend Setup

## Prerequisites
- Node.js 20+

## Run
1. Copy `.env.local.example` to `.env.local`.
2. Set `NEXT_PUBLIC_API_BASE_URL` to `http://localhost:5000`.
3. Install and run:
   - `npm install`
   - `npm run dev` (runs on `http://localhost:3000`)
